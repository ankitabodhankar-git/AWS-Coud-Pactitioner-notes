# Module 1 — Introduction to the Cloud ☁️

## Welcome to AWS Cloud Practitioner Essentials

AWS Cloud Practitioner Essentials introduces the basic concepts of cloud computing and AWS services.
This module explains how cloud computing works, why organizations use AWS, and how AWS manages global infrastructure and security.

---

# What is Cloud Computing?

Cloud computing means delivering IT resources over the internet on demand instead of owning and maintaining physical servers.

Resources include:

* Compute power
* Storage
* Databases
* Networking
* Software services

Users can access resources whenever needed and pay only for what they use.

---

## Characteristics of Cloud Computing

### On-Demand Access

Resources can be created instantly whenever required.

### Pay-As-You-Go Pricing

Users pay only for the services they use.

### Scalability

Resources can increase or decrease depending on demand.

### Elasticity

Automatic scaling of resources based on workload.

### Global Access

Applications and services can be accessed from anywhere.

---

## Real-Life Example

Netflix uses cloud computing to stream movies and shows globally without managing physical servers in every country.

# Introduction to AWS Global Infrastructure

AWS Global Infrastructure helps applications achieve:

* High availability
* Fault tolerance
* Low latency
* Global accessibility

---

# AWS Regions

A Region is a physical geographic location containing multiple Availability Zones.

### Examples

* Asia Pacific (Mumbai)
* US East (N. Virginia)
* Europe (London)

---

# Availability Zones (AZs)

Availability Zones are isolated data centers inside a Region.

Each Availability Zone has:

* Independent power
* Independent networking
* Independent cooling

### Benefits

* High availability
* Fault isolation
* Disaster recovery support

# Edge Locations

Edge locations help deliver content closer to users using caching services such as Amazon CloudFront.

---

# Multi-Region Deployment

Applications can run across multiple AWS Regions for:

* Backup
* Disaster recovery
* Better global performance

---

# AWS Shared Responsibility Model

Security responsibilities are shared between AWS and customers.

# AWS Responsibility — Security OF the Cloud

AWS manages:

* Physical data centers
* Hardware
* Networking
* Hypervisor
* Infrastructure security

---

# Customer Responsibility — Security IN the Cloud

Customers manage:

* Applications
* User permissions
* Data encryption
* Operating system updates
* Security configurations

---

# Real-Life Analogy

AWS secures the apartment building.

Customers secure:

* Apartment doors
* Passwords
* Personal belongings
